# 建仓与调仓规则

## 🎯 核心原则

> 建仓看"值不值得买"，调仓看"当前持仓是否仍是最优解"。

所有仓位决策必须经过两层验证：
1. **基本面验证**（PESTEL + SWOT）
2. **技术面验证**（净值历史分位，见 [nav-analysis.md](nav-analysis.md)）

两层均通过，才执行操作。

---

## 📊 一、建仓评分卡

> **设计原则**：政策和市场趋势是主题基金的核心驱动力，主导「是否建仓」；净值历史分位只影响「建多少」（仓位乘数），不参与评分，避免在政策牛市初期错误拦截入场。

### 评分维度（满分100分）

| 维度 | 满分 | 说明 |
|------|------|------|
| 宏观环境（PESTEL） | 35分 | 政策是主题基金最核心驱动，权重提升 |
| 估值水平（板块PE） | 20分 | 仅看板块PE历史分位，净值分位移出评分 |
| 动量信号 | 25分 | 市场趋势确认，权重提升 |
| 风险控制 | 20分 | 最大回撤 + 波动率 |

#### 1. 宏观环境评分（0-35分）

```
货币政策（0-12分）：
  - 宽松（降准/降息）：+12
  - 中性：+6
  - 收紧：+0

财政政策（0-11分）：
  - 扩张（专项债/减税）：+11
  - 中性：+5
  - 收缩：+0

产业政策（0-12分）：
  - 强支持（国家战略方向）：+12
  - 一般支持：+7
  - 中性：+3
  - 限制/整治：+0

  ⚠️ 消费行业专项修正（政策精准度系数）：
  当基金所在行业为"消费"时，产业政策得分需乘以政策精准度系数，
  防止"大方向有政策但持仓细分不受益"的虚假高分。

  十五五消费政策受益细分：
    强受益（系数 1.0）：银发经济、以旧换新（家电/汽车/家居）、特色产业/乡村消费、绿色消费
    中受益（系数 0.6）：大众餐饮、平价零售、基础食品饮料
    弱受益（系数 0.3）：高端白酒/奢侈品、可选消费（无专项政策支撑）

  政策精准度计算方法：
    Step 1：获取基金前十大重仓股
    Step 2：逐一判断每只股票属于上方哪个细分，取对应系数
    Step 3：加权平均（权重 = 持仓占比）
    Step 4：产业政策得分 × 加权平均系数

  示例：
    消费基金重仓茅台(8%)、五粮液(7%)、美的(6%)、海尔(5%)
    → 茅台/五粮液：高端白酒 → 系数 0.3
    → 美的/海尔：以旧换新受益 → 系数 1.0
    加权系数 = (0.3×8 + 0.3×7 + 1.0×6 + 1.0×5) / (8+7+6+5) = 0.596
    产业政策得分 = 12 × 0.596 = 7.2（而非满分 12）
```

#### 2. 估值水平评分（0-20分）

> 净值历史分位已移出评分，改为独立的仓位乘数（见下方"净值分位仓位乘数"）

```
板块 PE 历史分位（0-20分）：
  - 0-30% 分位（历史低估）：+20
  - 30%-50% 分位：+12
  - 50%-70% 分位：+6
  - 70%+ 分位（历史高估）：+0
```

#### 3. 动量信号评分（0-25分）

```
近3个月净值趋势（0-12分）：
  - 止跌企稳，开始反弹：+12
  - 横盘震荡：+7
  - 下跌中，但速度放缓：+3
  - 持续下跌：+0

资金流向（近7天）（0-13分）：
  - 持续大额净流入（>5亿）：+13
  - 持续净流入：+10
  - 轻微净流入：+6
  - 中性：+3
  - 净流出：+0
```

#### 4. 风险控制评分（0-20分）

```
近1年最大回撤（0-10分）：
  - < 15%：+10（低波动）
  - 15%-25%：+6
  - 25%-35%：+3
  - > 35%：+0（高风险）

基金规模（0-10分）：
  - 50亿-200亿（最优区间，灵活且稳定）：+10
  - 10亿-50亿 或 200亿-500亿：+6
  - < 10亿（清盘风险）或 > 500亿（规模拖累）：+2
```

### 建仓决策标准

```
总分 ≥ 70 → ✅ 可建仓
总分 55-69 → ⚠️ 观望，设价格预警（当板块PE分位降至30%以下时重新评估）
总分 < 55 → ❌ 不建仓
```

> ⚠️ **内卷强制覆盖**：无论总分多高，若内卷烈度指数 ≥ 60，强制将建仓上限降至目标仓位的 20%（见第六节）

### 净值分位仓位乘数（独立于评分卡）

评分卡决定「是否建仓」，净值分位单独决定「建多少」：

| 净值历史分位（近5年，与五年规划周期对齐） | 仓位乘数 | 说明 |
|-------------------|---------|------|
| 0% - 25% | ×1.0 | 历史低位，全额建仓 |
| 25% - 45% | ×0.8 | 偏低，正常建仓 |
| 45% - 65% | ×0.6 | 中性，适度控制 |
| 65% - 80% | ×0.4 | 偏高，轻仓试探 |
| 80%+ | ×0.2 | 历史高位，极轻仓（等回调加仓） |

**设计逻辑**：政策强支持时仍可入场，但用更轻的仓位为「预期落空」留余地；净值高位不等于不该买，只是降低初始仓位保护自己。

### 初始仓位计算公式

```
初始仓位 = 目标仓位 × 50% × 净值分位仓位乘数 × 波动率系数

示例（政策强支持，净值在80%分位，波动率28%）：
  目标仓位 40% × 50% × 0.2 × 0.65 = 2.6%（极轻试探）

示例（政策强支持，净值在30%分位，波动率20%）：
  目标仓位 40% × 50% × 0.8 × 0.8 = 12.8%（正常建仓）

高位轻仓的回调加仓规则（净值分位 > 65% 时启用）：
  第一档：净值从建仓点回调 8%，追加至乘数上升一档对应仓位
  第二档：净值从建仓点回调 15%，继续追加
  前提：每档加仓前必须确认基本面未恶化（PE分位未继续上升）
```

## 🔄 二、调仓触发条件

### 加仓触发（同时满足以下条件）

```
条件一（技术面）：净值从近期高点回调 ≥ 10%
条件二（基本面）：重仓股基本面未恶化（最近季报/财报正常）
条件三（趋势面）：回调过程中资金流向未出现持续净流出
```

### 减仓触发（满足任一条件）

```
触发一：仓位占总资产比例 > 设定上限（默认70%）
触发二：净值从持仓成本上涨超过 30%，锁定部分收益（减仓 1/4）
触发三：PESTEL 出现重大负面变化（政策反转、行业景气下行）
触发四：连续 2 轮预测验证偏差 > 15%（分析框架失效信号）
触发五：基金经理更换（高权重信号，需立即重新评估是否继续持有）
```

### 换仓触发（同时满足以下条件）

```
条件一：当前持仓基金建仓评分 < 55
条件二：备选基金建仓评分 > 当前基金评分 × 0.8 + 15

（注：× 0.8 + 15 设计目的是要求备选基金明显更好，
 避免频繁换仓带来的交易摩擦和时间成本）
```

### 止损触发（满足任一条件，强制执行）

```
触发一：净值从持仓成本下跌 ≥ 25%，且基本面持续恶化
触发二：基金公司出现重大合规风险（监管处罚、清算警告）
触发三：基金规模连续3个季度缩减超过50%（资金持续出逃）
```

## ⚠️ 四、换仓摩擦成本提示

换仓前必须评估以下成本，确保收益覆盖摩擦：

```
换仓总成本 = 赎回费（当前基金）+ 申购费（新基金）+ 资金空档期损失
  
持有不足7天：赎回费约1.5%
持有7天-1年：赎回费约0.5%
持有1年以上：赎回费约0%（部分基金）

建议：仅当预期新基金在下一个评估周期（3个月）的超额收益 > 1.5% 时，才执行换仓
```

## 🔢 五、组合层面风险检查

### 调仓时同步执行以下检查

#### 1. 行业集中度

```
检查规则：单一行业在持仓组合中的暴露比例不超过 50%

计算方式：
  行业暴露 = Σ（基金持仓该行业占比 × 该基金在组合中的权重）

示例：
  003984 新能源占比 45%，组合权重 50% → 新能源暴露 = 45% × 50% = 22.5%
  005827 新能源占比 10%，组合权重 30% → 新能源暴露 = 10% × 30% = 3%
  总新能源暴露 = 25.5% → ✅ 正常
```

#### 2. 持仓相关性检查

```
高风险信号：持有多只重仓股高度重叠的基金
  
检查方法：
  - 对比各基金前十大重仓股
  - 若两只基金的前十大重仓股重叠 ≥ 5 只 → ⚠️ 相关性过高，实际分散化不足
  - 建议持仓中相关性高的基金总权重不超过 40%
```

#### 3. 再平衡触发

```
触发条件：某只基金因净值变化导致实际仓位偏离目标仓位 ≥ 15%

示例：
  目标配置：003984 占组合 40%
  当前实际：003984 因大涨占比升至 58% → 偏离 18% → 触发再平衡
  操作：减仓 003984 至 40%，将资金再分配至其他标的
```

## 🚨 六、内卷烈度指数（强制覆盖规则）

> 内卷是中国政策驱动型行业特有的结构性崩溃机制：强政策 → 大量资本涌入 → 产能过剩 → 价格战 → 行业毛利率崩溃 → 净值腰斩。此风险凌驾于所有其他评分之上。

### 典型案例参照

| 行业 | 政策强度 | 内卷结果 |
|------|---------|---------|
| 光伏（2022-2024） | 极强 | 硅料 300→40元/kg，组件价格腰斩 |
| 新能源汽车（2023-） | 极强 | 百余品牌价格战，多家倒闭 |
| 锂电池（2023-） | 极强 | 碳酸锂 60万→7万/吨 |
| 半导体成熟制程（2024-） | 极强 | 28nm 产能严重过剩 |

### 内卷烈度评分（0-100）

```
① 新进入者数量（0-30分）
  近1年新增产能规划 / 当前总产能 > 50% → +25
  近1年新增企业数量 > 行业历史均值2倍 → +5

② 关键产品价格跌幅（0-30分）
  核心产品价格近半年跌幅 15%-30% → +15
  跌幅 30%-50% → +25
  跌幅 > 50% → +30

③ 毛利率压缩速度（0-25分）
  行业平均毛利率连续2季度下滑 → +15
  头部企业毛利率也开始下滑（同步恶化） → +10

④ 政策信号（0-15分）
  政府出现「整治恶性竞争/防止内卷」表态 → +10
  行业协会呼吁自律/限产 → +5
```

### 内卷烈度对仓位的强制影响

| 内卷烈度分 | 对建仓评分的调整 | 仓位上限强制覆盖 |
|-----------|--------------|----------------|
| < 40 | 不调整 | 无限制 |
| 40-59 | 建仓评分额外扣 20 分 | 无额外限制 |
| ≥ 60 | 建仓评分额外扣 30 分 | **强制上限：目标仓位的 20%** |
| ≥ 80（极度内卷） | — | **强制清仓或空仓** |

> **说明**：内卷烈度 ≥ 60 时，即使政策再强、建仓评分再高，最大仓位也不超过目标仓位的 20%。此时政策利好已被竞争结构性破坏，行业盈利能力的恶化将持续反映在净值上。

### 内卷烈度监控频率

- **每月**更新一次（关键产品价格、新增产能数据）
- **季度财报发布后**立即更新（毛利率数据）
- **政府出现相关表态时**立即更新（政策信号）
