# 净值历史分析规范

## 🎯 核心定位

净值历史分析在决策体系中承担两个独立职责：

1. **仓位乘数**：净值分位决定「建多少」，不参与建仓评分卡
2. **联合判断**：结合板块PE分位，识别「强政策+净值高位」特殊场景，防止误判

> **原则**：净值历史决定「何时买入」和「买多少」，基本面决定「是否值得买入」。两者角色不可混淆。

---

## ⚠️ 重要前提

使用净值历史时，必须注意以下约束：

```
1. 数据时间范围：以5年为基本单位，对齐国内五年规划周期
   （五年规划决定一个行业的完整景气周期，用更短的窗口容易将周期局部误判为"历史高位"）

   分层使用规则：
   - 主要分位参考：近5年（覆盖完整一个规划周期）
   - 辅助参考：近10年（跨两个规划周期，识别长期结构性变化）
   - 基金经理任职不足5年：取任职以来全部数据，并在报告中注明数据局限性

2. 数据时间起点约束：仍需与基金经理任职时间取交集
   （基金经理更换后，历史净值参考价值大幅降低，不可跨经理使用）

3. 数据来源：
   - 天天基金网（https://fund.eastmoney.com）
   - 蛋卷基金（https://danjuanfunds.com）
   - 基金公司官网
```

## 📊 一、核心分析指标

### 1. 净值历史分位数

**定义**：当前净值在近5年历史净值中所处的百分比位置

**为什么用5年**：国内五年规划是行业景气周期的基本单位，用2年窗口可能恰好只覆盖牛市半段，导致当前净值在"2年高位"但实际处于"5年中位"，产生错误的高位信号。

**计算方法**：
```python
def calculate_nav_percentile(current_nav, historical_navs):
    """
    计算当前净值的历史分位数
    
    Args:
        current_nav: 当前净值（float）
        historical_navs: 近5年历史净值列表（list of float）
                        若基金经理任职不足5年，取任职以来全部数据
    
    Returns:
        percentile: 0-100 的分位数
    """
    count_below = sum(1 for nav in historical_navs if nav <= current_nav)
    percentile = (count_below / len(historical_navs)) * 100
    return round(percentile, 1)

# 示例
historical_navs = [2.8, 2.9, 3.0, 3.1, 3.2, 3.3, 3.4, 3.5]  # 近5年净值
current_nav = 3.1
percentile = calculate_nav_percentile(current_nav, historical_navs)
# 输出：37.5（处于历史38%分位，偏低）
```

**分位解读**：

| 分位区间 | 含义 | 仓位乘数（见 position-management.md） |
|---------|------|--------------------------------------|
| 0% - 25% | 历史低位 | ×1.0 |
| 25% - 45% | 偏低 | ×0.8 |
| 45% - 65% | 历史中位 | ×0.6 |
| 65% - 80% | 偏高 | ×0.4 |
| 80% - 100% | 历史高位 | ×0.2 |

> 净值分位不再作为建仓评分输入，仅作为仓位乘数使用。

### 2. 均值回归分析

**定义**：当前净值与近5年均值的偏离程度

```python
def mean_reversion_signal(current_nav, historical_navs):
    """
    均值回归分析
    
    Returns:
        deviation_pct: 偏离均值的百分比（负值=低于均值）
        signal: 信号描述
    """
    mean_nav = sum(historical_navs) / len(historical_navs)
    deviation_pct = (current_nav - mean_nav) / mean_nav * 100
    
    if deviation_pct < -15:
        signal = "⬆️ 强均值回归信号（大幅低于均值）"
    elif deviation_pct < -5:
        signal = "⬆️ 弱均值回归信号（低于均值）"
    elif deviation_pct < 5:
        signal = "➡️ 中性（接近均值）"
    elif deviation_pct < 15:
        signal = "⬇️ 弱高估信号（高于均值）"
    else:
        signal = "⬇️ 强高估信号（大幅高于均值）"
    
    return deviation_pct, signal
```

### 3. 近期回撤分析

**定义**：从近期高点下跌的幅度，用于识别底部特征

```python
def drawdown_analysis(historical_navs, window=90):
    """
    分析近90天的回撤情况
    
    Returns:
        max_drawdown: 最大回撤百分比
        current_drawdown: 当前从高点的回撤百分比
        is_recovering: 是否已从低点反弹
    """
    recent_navs = historical_navs[-window:]
    peak = max(recent_navs)
    current = recent_navs[-1]
    trough = min(recent_navs)
    
    max_drawdown = (peak - trough) / peak * 100
    current_drawdown = (peak - current) / peak * 100
    is_recovering = current > trough * 1.03  # 从低点反弹超过3%视为企稳
    
    return max_drawdown, current_drawdown, is_recovering
```

**底部特征判断**：
```
底部信号（同时满足以下条件）：
  ✅ 当前回撤距高点 > 15%（调整充分）
  ✅ 当前净值从最低点反弹 ≥ 3%（开始企稳）
  ✅ 近7天净值连续3天上涨（趋势确认）
```

### 4. 波动率（风险量化）

**用途**：决定建仓仓位大小——波动越大，初始仓位越小

```python
import statistics

def calculate_volatility(daily_returns):
    """
    计算近60天日涨跌幅的年化波动率
    
    Args:
        daily_returns: 每日涨跌幅列表（如 [0.012, -0.008, ...]）
    
    Returns:
        annualized_vol: 年化波动率（百分比）
    """
    daily_std = statistics.stdev(daily_returns)
    annualized_vol = daily_std * (252 ** 0.5) * 100  # 年化
    return round(annualized_vol, 1)
```

**仓位调整系数**：

| 年化波动率 | 仓位系数 | 说明 |
|-----------|---------|------|
| < 15% | ×1.0 | 低波动，按目标仓位建仓 |
| 15% - 25% | ×0.8 | 中等波动，适度降低仓位 |
| 25% - 35% | ×0.65 | 较高波动，明显降低仓位 |
| > 35% | ×0.5 | 高波动，仓位减半 |

**示例**：目标仓位 40%，年化波动率 28% → 实际建仓 = 40% × 0.65 = 26%

### 5. 200日均线信号

```
当前净值 < 200日均线：
  - 短期偏空，但属于均值回归机会
  - 结合底部特征判断是否建仓

当前净值 > 200日均线：
  - 中长期趋势偏多
  - 但若净值分位 > 80%，仍需谨慎
```

## 🔧 二、技术面综合信号

### 数据窗口降级策略

```
优先级顺序：
  1. 近5年数据（基金经理任职 ≥ 5年）         → 完整周期，最可靠
  2. 近3年数据（任职 3-5年）                  → 跨越一半规划周期，可用
  3. 任职以来全部数据（任职 < 3年）           → 数据不足，需在报告中注明
     注明格式："⚠️ 数据仅覆盖 X 年，分位参考价值有限，需加重基本面权重"

辅助参照（数据充足时同步计算）：
  - 近10年分位：识别长期结构性变化（如行业整体景气抬升）
  - 当5年分位 > 80% 但 10年分位 < 50% → 说明当前仍处10年维度的中低位，
    更可能是五年规划驱动的新一轮景气周期启动，而非单纯高位泡沫
```

### 五年规划周期与分位的对应关系

```
当前五年规划：十五五（2026-2030）
上一轮：十四五（2021-2025）

使用5年窗口的意义：
  若当前处于十五五初期（2026年），用近5年（2021-2026）数据：
  → 能覆盖十四五完整周期的净值变动
  → "历史高位"意味着超越了上一轮规划周期的顶点，是真高位
  → 若只用近2年（2024-2026），可能恰好只看到十四五末的局部反弹，
    产生虚假的"高位"判断

规划切换期的特别注意：
  新规划发布后前1年（如2026年）：
  → 行业净值可能系统性抬升，历史5年分位整体失真
  → 此时应更重视 PE分位 和 内卷烈度，降低净值分位权重
```

将以上指标汇总为统一信号：

```markdown
## 净值技术面分析 - 003984 嘉实新能源新材料

**数据范围**：2021-05-07 至 2026-05-07（近5年，覆盖十四五完整周期）
**数据说明**：基金经理任职自2020年，数据充足，5年窗口有效

| 指标 | 数值 | 信号 |
|------|------|------|
| 当前净值分位（近5年） | 38% | ✅ 偏低，技术面支持 |
| 当前净值分位（近10年，辅助） | 32% | ✅ 10年维度也偏低 |
| 均值偏离度 | -8.3% | ✅ 低于均值，均值回归机会 |
| 近期最大回撤 | -18.5% | ✅ 调整充分 |
| 底部企稳信号 | 已从低点反弹4.2% | ✅ 企稳 |
| 年化波动率 | 26.3% | ⚠️ 仓位系数 ×0.65 |
| 200日均线 | 净值在均线下方 | ⚠️ 偏空，但接近均线 |

**技术面综合结论**：✅ 技术面支持建仓（4个正面信号）
**建议仓位系数**：×0.65（因波动率偏高）
```

## 📈 三、建仓决策流程

```
Step 1: 基本面验证（建仓评分卡）
  → 执行 PESTEL + SWOT 分析
  → 输出建仓评分卡（见 position-management.md，满分100）
  → 评分 ≥ 70 → 继续 Step 2
  → 评分 < 70 → 停止，不建仓

Step 2: 内卷烈度检查（强制覆盖）
  → 计算内卷烈度指数（见 position-management.md 第六节）
  → 烈度 ≥ 60 → 仓位上限强制降至目标仓位 20%
  → 烈度 < 40 → 不影响，继续

Step 3: 净值分位联合判断（特殊场景识别）
  → 计算净值历史分位 + 板块PE分位
  → 进入联合判断矩阵（见下方第四节）
  → 输出：场景类型 + 建议操作

Step 4: 确定仓位参数
  → 初始仓位 = 目标仓位 × 50% × 净值分位仓位乘数 × 波动率系数
  → 设定高位轻仓的回调加仓触发点
  → 设定止损线（从建仓成本下跌25%）
```

## 🔢 四、强政策 + 净值高位联合判断矩阵

此矩阵专门处理「强政策支持但净值已在历史高位」的场景，防止误判。

### PE分位 × 净值分位 联合矩阵

|  | 净值分位 < 65%（合理） | 净值分位 65-80%（偏高） | 净值分位 > 80%（历史高位） |
|--|----------------------|----------------------|--------------------------|
| **板块PE < 50%** | ✅ 建仓评分支持<br>仓位乘数正常 | ⚠️ 情况A：盈利驱动<br>轻仓入场（×0.4） | ⚠️ 情况A：强基本面<br>极轻仓（×0.2），等回调 |
| **板块PE 50-70%** | ✅ 正常建仓 | ⚠️ 谨慎，等待PE回落 | ❌ 情况B：估值透支<br>不建仓 |
| **板块PE > 70%** | ⚠️ 评分已扣分，谨慎 | ❌ 情况B：双高<br>不建仓 | 🚨 情况B：泡沫风险<br>已持仓应减仓 |

### 情况A：盈利驱动的合理高位

**识别条件**（同时满足）：
```
净值分位 > 65%  AND  板块PE分位 < 50%
→ 净值涨幅 > PE涨幅，说明盈利增速比估值扩张更快
→ 属于基本面改善带来的合理重新定价（structural re-rating）
```

**建议操作**：
```
可以入场，但必须极轻仓（仓位乘数 ×0.2）
设定严格的回调加仓条件：
  - 净值回调 8% 且 PE分位未继续上升 → 加仓至乘数 ×0.4
  - 净值回调 15% 且 基本面未恶化 → 加仓至乘数 ×0.6
```

### 情况B：情绪透支的危险高位

**识别条件**（满足任一）：
```
净值分位 > 80%  AND  板块PE分位 > 70%
→ 价格涨得比盈利快得多，属于纯情绪/预期驱动
```

**「政策 price in」识别信号**：
```
信号一：政策宣布已超过3个月，市场充分消化
信号二：资金流入开始放缓（近7天净流入 < 近30天均值的50%）
信号三：分析师一致预期已上调至乐观上限（机构目标价普遍上调后趋于一致）
信号四：散户情绪极度亢奋（社交媒体讨论量异常放大）

满足2个以上信号 → 判定政策已 price in，建议不入场或减仓
```

**建议操作**：
```
新建仓：❌ 不建仓，等待以下任一条件再重新评估：
  - 净值回调至 65% 分位以下
  - 板块PE分位回落至 50% 以下

已持仓：⚠️ 考虑分批减仓
  - 减仓 1/3：当资金流向转为净流出
  - 再减仓 1/3：当净值从高点回调超过 8%
  - 保留底仓 1/3：应对政策超预期的可能
```
