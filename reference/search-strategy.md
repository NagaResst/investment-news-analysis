# 搜索策略详解

## 🎯 核心原则

搜索策略采用**分层搜索 + 统一政策分析**的模式：

1. **针对每个基金单独搜索**相关新闻和动态
2. **统一搜索国家新政**，然后分析政策对每个基金的影响
3. **如果本地存在高度相似新闻**，不要归档到本地

---

## 📋 搜索流程

### 阶段一：加载本地历史数据（优先执行）

**目的**：从本地归档文件中读取基金的历史趋势信息

**操作步骤**：

1. **读取 index.json**
   ```python
   # 位置：日常工作流/投资新闻归档/index.json
   # 获取所有历史 summary 的路径列表
   ```

2. **筛选目标基金的歷史记录**
   - 遍历 index.json 中的 summary 文件
   - 提取包含目标基金代码/名称的记录
   - 按时间倒序排列（最近的在前）

3. **提取趋势指标**
   从最近 5-10 条 summary 中提取：
   - **资金流向**：净流入/净流出趋势

   - **机构评级变化**：上调/下调/维持

4. **构建历史画像**


### 阶段二：针对每个基金单独搜索

**搜索对象**：用户提供的基金列表（如：003984、005827等）

**搜索层次**（按优先级）：

#### 1️⃣ 基金本身信息（最高优先级）

**搜索关键词**：
```
"{基金代码}" OR "{基金全称}" OR "{基金简称}"
```

**搜索内容**：
- ✅ 最新净值数据（今日/昨日）
- ✅ 基金经理变更/观点
- ✅ 季报/年报发布
- ✅ 规模变化（申购/赎回）
- ✅ 分红公告
- ✅ 费率调整

**示例**：
```
搜索："003984" OR "长城久富核心成长混合"
目标：获取基金最新动态
```

#### 2️⃣ 重仓股动态（次高优先级）

**前置步骤**：从本地数据或基金季报获取前十大重仓股

**搜索关键词**：
```
"{重仓股名称}" AND ("财报" OR "业绩" OR "评级" OR "新闻")
```

**搜索内容**：
- ✅ 最新财报发布（营收/利润/增速）
- ✅ 机构评级调整（买入/增持/中性/减持）
- ✅ 重大事件（并购/重组/处罚/诉讼）
- ✅ 股价异动及原因
- ✅ 行业地位变化

**示例**：
```
搜索："宁德时代" AND ("Q1财报" OR "业绩预增")
搜索："贵州茅台" AND ("机构评级" OR "目标价")
```

**权重计算**：
```
影响分数 = 重仓占比 × 个股新闻重要性
例：宁德时代占比8.5%，发布利好财报 → 影响分数 = 8.5 × 0.8 = 6.8
```

#### 3️⃣ 行业政策与动态

**搜索关键词**：
```
"{行业名称}" AND ("政策" OR "监管" OR "供需" OR "技术突破")
```

**搜索内容**：
- ✅ 国家政策（补贴/限制/标准）
- ✅ 行业供需格局变化
- ✅ 技术突破/创新
- ✅ 竞争格局变化（新进入者/退出者）
- ✅ 原材料价格波动

**示例**：
```
搜索："新能源汽车" AND ("补贴政策" OR "渗透率")
搜索："白酒行业" AND ("消费税" OR "高端化")
```

### 阶段三：统一搜索国家新政

**目的**：获取宏观政策信息，然后分析对每个基金的影响

**搜索关键词**：
```
("国务院" OR "央行" OR "财政部" OR "发改委") AND 
("新政" OR "政策" OR "会议" OR "讲话") 
时间范围：最近7天
```

**搜索内容**：
- ✅ 国务院常务会议要点
- ✅ 央行货币政策（降准/降息/MLF）
- ✅ 财政政策（专项债/减税降费）
- ✅ 产业政策（十四五规划/行业支持）
- ✅ 地缘政治（贸易摩擦/国际关系）
- ✅ 经济数据（GDP/CPI/PPI/PMI）

**示例**：
```
搜索："国务院" AND ("常务会议" OR "政策解读") 最近7天
搜索："央行" AND ("降准" OR "LPR") 最近7天
搜索："财政部" AND ("专项债" OR "赤字率") 最近7天
```

### 阶段四：政策影响分析（交叉分析）

**目的**：将阶段三获取的国家新政，逐一分析对每个基金的影响

**分析框架**：

#### 1. 政策分类
```
├── 货币政策（宽松/紧缩）
├── 财政政策（扩张/收缩）
├── 产业政策（支持/限制）
├── 监管政策（加强/放松）
└── 国际政策（合作/摩擦）
```

#### 2. 影响路径分析
```
政策 → 行业影响 → 重仓股影响 → 基金影响
```

**示例分析**：

**政策**：央行宣布降准0.5个百分点

**影响分析**：
```
| 基金代码 | 主要持仓行业 | 影响方向 | 影响程度 | 逻辑链条 |
|---------|------------|---------|---------|---------|
| 003984  | 新能源(45%) | ✅ 利好 | 中等    | 降准→流动性增加→成长股估值提升→新能源受益 |
| 005827  | 银行(60%)   | ⚠️ 中性 | 轻微    | 降准→息差收窄但贷款量增→对冲效应 |
| 006567  | 消费(50%)   | ✅ 利好 | 轻微    | 降准→刺激消费→可选消费受益 |
```

#### 3. 综合评分
```
基金政策影响分 = Σ(政策数量 × 政策强度 × 持仓占比)

政策强度：
- 重大政策（降准/财政刺激）：1.0
- 一般政策（行业指导）：0.6
- 轻微政策（表态/讲话）：0.3
```

## 🔍 搜索技巧

### 1. 时间范围控制

**优先级**：
- 🥇 最近3天：最重要，必须搜索
- 🥈 最近7天：重要，建议搜索
- 🥉 最近30天：补充，可选搜索

**搜索语法**：
```
site:财联社.com "{关键词}" after:2026-04-20
site:东方财富网 "{关键词}" 最近一周
```

### 2. 来源权威性排序

**优先级**：
1. **官方渠道**：证监会、交易所、基金公司官网
2. **头部媒体**：财联社、证券时报、中国证券报
3. **券商研报**：中信、中金、华泰、国泰君安
4. **数据平台**：东方财富、同花顺、Wind

### 3. 去重策略

**避免重复搜索**：
- 检查本地 `raw_data/` 目录，已抓取的数据不再重复搜索
- 相同新闻来源只抓取一次
- 相似标题的新闻合并处理

## 📊 搜索结果评估

### 关联性评分（0-100分）

**评分维度**：

| 维度 | 分值 | 说明 |
|-----|------|------|
| 直接提及基金代码 | +40分 | 明确提到基金代码或全称 |
| 涉及重仓股 | +30分 | 根据持仓占比加权（占比×30） |
| 信息来源权威 | +20分 | 官方/头部媒体得满分 |
| 时效性强 | +10分 | 3天内=10分，7天内=7分，30天内=3分 |

**评级标准**：
- **高关联 (80-100分)**：必须保存，生成单条 summary
- **中关联 (50-79分)**：建议保存，生成单条 summary
- **低关联 (<50分)**：不保存，仅记录在日志

**示例**：
```
新闻：宁德时代发布Q1财报，净利润增长48.5%

评分计算：
- 未直接提及基金代码：0分
- 涉及重仓股（占比8.5%）：8.5% × 30 = 25.5分
- 来源：财联社（权威）：20分
- 时效：今天发布：10分
总分：55.5分 → 中关联，建议保存
```

## 📁 搜索结果保存

### 即时保存原则

**每轮搜索后立即保存**，不要等到最后统一保存！

**保存内容**：
1. **原始数据**：JSON格式，保存到 `raw_data/`
2. **单条 Summary**：Markdown格式，保存到 `item_summaries/`
3. **更新索引**：添加到当日 summary 草稿

**保存路径**：
```
日常工作流/投资新闻归档/2026-04/2026-04-26/
├── raw_data/
│   ├── fund_003984_news.json      # 基金新闻
│   ├── stocks/宁德时代.json        # 重仓股新闻
│   └── policy_2026-04-26.json     # 政策新闻
└── item_summaries/
    ├── 001_宁德时代Q1财报.md
    └── 002_央行降准政策解读.md
```

## ⚠️ 注意事项

1. **先本地后网络**：优先读取本地历史数据，减少重复搜索
2. **针对性搜索**：每个基金单独搜索，不要混在一起
3. **政策统一分析**：国家政策统一搜索，然后逐个分析对各基金的影响
4. **即时归档**：每轮搜索后立即保存，防止数据丢失
5. **来源标注**：每条信息必须标注来源和时间
6. **去重检查**：搜索前检查是否已存在相同内容
