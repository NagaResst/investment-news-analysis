# 搜索策略详解

## 🎯 核心原则

搜索策略采用**分层搜索 + 统一政策分析 + 竞品扫描**的模式：

1. **针对每个基金单独搜索**相关新闻和动态
2. **统一搜索国家新政**，然后分析政策对每个基金的影响
3. **扫描同类竞品基金**，为调仓决策提供横向比较数据
4. **判断经济周期阶段**，指导行业配置方向
5. **如果本地存在高度相似新闻**，不要归档到本地

## 📋 搜索流程

### 阶段一：加载本地历史数据（优先执行）

**目的**：从本地归档文件中读取基金的历史趋势信息

**操作步骤**：

1. **读取 index.json**
   ```python
   # 位置：投资新闻归档/index.json
   # 获取所有历史 summary 的路径列表
   ```

2. **筛选目标基金的歷史记录**
   - 遍历 index.json 中的 summary 文件
   - 提取包含目标基金代码/名称的记录
   - 按时间倒序排列（最近的在前）

3. **提取趋势指标**
   从最近 5-10 条 summary 中提取：
   - **资金流向**：净流入/净流出趋势
   - **舆情指数**：正面/负面新闻比例
   - **机构评级变化**：上调/下调/维持
   - **净值走势**：近期涨跌幅
   - **重仓股变动**：季度调仓情况

4. **构建历史画像**
   ```markdown
   ### 基金历史趋势画像
   
   **近1个月**：
   - 资金流向：持续净流入（+12.5亿）
   - 舆情指数：偏正面（75%正面新闻）
   - 机构评级：2家上调，1家维持
   
   **近3个月**：
   - 净值波动：+8.3%
   - 最大回撤：-5.2%
   - 重仓股稳定性：前十大持仓变化率15%
   ```

**详细说明**：参见 [历史数据引用规范](historical-data.md)

### 阶段二：针对每个基金单独搜索

**搜索对象**：用户提供的基金列表（如：003984、005827等）

**搜索层次**（按优先级）：

#### 1️⃣ 基金本身信息（最高优先级）

**搜索关键词**：
```
"{基金代码}" OR "{基金全称}" OR "{基金简称}"
```

**搜索内容**：
- ✅ 最新净值数据（今日/昨日）
- ✅ 基金经理变更/观点
- ✅ 季报/年报发布
- ✅ 规模变化（申购/赎回）
- ✅ 分红公告
- ✅ 费率调整

**示例**：
```
搜索："003984" OR "长城久富核心成长混合"
目标：获取基金最新动态
```

#### 2️⃣ 重仓股动态（次高优先级）

**前置步骤**：从本地数据或基金季报获取前十大重仓股

**搜索关键词**：
```
"{重仓股名称}" AND ("财报" OR "业绩" OR "评级" OR "新闻")
```

**搜索内容**：
- ✅ 最新财报发布（营收/利润/增速）
- ✅ 机构评级调整（买入/增持/中性/减持）
- ✅ 重大事件（并购/重组/处罚/诉讼）
- ✅ 股价异动及原因
- ✅ 行业地位变化

**示例**：
```
搜索："宁德时代" AND ("Q1财报" OR "业绩预增")
搜索："贵州茅台" AND ("机构评级" OR "目标价")
```

**权重计算**：
```
影响分数 = 重仓占比 × 个股新闻重要性
例：宁德时代占比8.5%，发布利好财报 → 影响分数 = 8.5 × 0.8 = 6.8
```

#### 3️⃣ 行业政策与动态

**搜索关键词**：
```
"{行业名称}" AND ("政策" OR "监管" OR "供需" OR "技术突破")
```

**搜索内容**：
- ✅ 国家政策（补贴/限制/标准）
- ✅ 行业供需格局变化
- ✅ 技术突破/创新
- ✅ 竞争格局变化（新进入者/退出者）
- ✅ 原材料价格波动

**消费行业专项：细分赛道识别（消费类基金必须执行）**

当基金属于消费主题时，需额外执行以下搜索，识别政策真正指向的细分赛道：

```
搜索格式：
  "十五五" AND "消费" AND ("细分" OR "重点方向" OR "专项政策")
  "银发经济" OR "以旧换新" OR "特色产业" AND "消费" AND "政策"

输出：消费政策细分赛道列表 + 对应重仓股的对齐度评估

示例输出：
  十五五消费政策重点细分：
    ① 银发经济 → 重仓股中无直接受益标的
    ② 以旧换新 → 美的(6%)、海尔(5%) 直接受益 ✅
    ③ 特色产业/乡村消费 → 海天味业(4%) 弱对齐 ⚠️
    ④ 高端白酒 → 茅台(8%)、五粮液(7%) 无专项政策 ❌

  持仓政策对齐度：约35%（11/30的持仓权重真正对齐政策细分）
  → 产业政策精准度系数：0.3×0.5 + 1.0×0.37 + 0.6×0.13 = 0.596
```

**示例**：
```
搜索："新能源汽车" AND ("补贴政策" OR "渗透率")
搜索："白酒行业" AND ("消费税" OR "高端化")
搜索："银发经济" AND ("十五五" OR "政策支持") 2026年
```

### 阶段三：统一搜索国家新政

**目的**：获取宏观政策信息，然后分析对每个基金的影响

**搜索关键词**：
```
("国务院" OR "央行" OR "财政部" OR "发改委") AND 
("新政" OR "政策" OR "会议" OR "讲话") 
时间范围：最近7天
```

**搜索内容**：
- ✅ 国务院常务会议要点
- ✅ 央行货币政策（降准/降息/MLF）
- ✅ 财政政策（专项债/减税降费）
- ✅ 产业政策（十四五规划/行业支持）
- ✅ 地缘政治（贸易摩擦/国际关系）
- ✅ 经济数据（GDP/CPI/PPI/PMI）

**示例**：
```
搜索："国务院" AND ("常务会议" OR "政策解读") 最近7天
搜索："央行" AND ("降准" OR "LPR") 最近7天
搜索："财政部" AND ("专项债" OR "赤字率") 最近7天
```

### 阶段四：政策影响分析（交叉分析）

**目的**：将阶段三获取的国家新政，逐一分析对每个基金的影响

**分析框架**：

#### 1. 政策分类
```
├── 货币政策（宽松/紧缩）
├── 财政政策（扩张/收缩）
├── 产业政策（支持/限制）
├── 监管政策（加强/放松）
└── 国际政策（合作/摩擦）
```

#### 2. 影响路径分析
```
政策 → 行业影响 → 重仓股影响 → 基金影响
```

**示例分析**：

**政策**：央行宣布降准0.5个百分点

**影响分析**：
```
| 基金代码 | 主要持仓行业 | 影响方向 | 影响程度 | 逻辑链条 |
|---------|------------|---------|---------|---------|
| 003984  | 新能源(45%) | ✅ 利好 | 中等    | 降准→流动性增加→成长股估值提升→新能源受益 |
| 005827  | 银行(60%)   | ⚠️ 中性 | 轻微    | 降准→息差收窄但贷款量增→对冲效应 |
| 006567  | 消费(50%)   | ✅ 利好 | 轻微    | 降准→刺激消费→可选消费受益 |
```

#### 3. 综合评分
```
基金政策影响分 = Σ(政策数量 × 政策强度 × 持仓占比)

政策强度：
- 重大政策（降准/财政刺激）：1.0
- 一般政策（行业指导）：0.6
- 轻微政策（表态/讲话）：0.3
```

## 🔍 搜索技巧

### 1. 时间范围控制

**优先级**：
- 🥇 最近3天：最重要，必须搜索
- 🥈 最近7天：重要，建议搜索
- 🥉 最近30天：补充，可选搜索

**搜索语法**：
```
site:财联社.com "{关键词}" after:2026-04-20
site:eastmoney.com "{关键词}" 最近一周
"{关键词}" site:xueqiu.com after:2026-05-01
```

### 2. 关键词多样化策略（避免搜索死角）

**同义词扩展**：对每个核心概念同时使用多组同义词，避免漏掉不同措辞的相关新闻

```
# 不要只搜一种说法，而是覆盖多种表述：
利好 → "利好" OR "积极信号" OR "向好" OR "正面影响" OR "受益"
下跌 → "下跌" OR "回调" OR "走低" OR "跌幅" OR "缩水"
政策支持 → "政策支持" OR "政策利好" OR "获得支持" OR "纳入规划" OR "重点布局"
```

**宽泛搜索 + 精确过滤**：先用宽泛词获取更多结果，再用关联性评分过滤
```
# 宽泛搜索（覆盖更广）
"{重仓股}" 最新消息 2026

# 而不是过窄的限定搜索
"{重仓股}" AND ("Q1财报" OR "业绩预增")  ← 会漏掉战略合作、监管、评级等其他重要新闻
```

**模糊匹配技巧**：
```
使用双引号锁定核心词，其余词不加引号：
"宁德时代" 合作 海外工厂      ← 比 "宁德时代" AND "海外工厂" 覆盖更广
"新能源基金" 政策 2026        ← 不限定AND，覆盖更多政策表述
```

### 2. 来源权威性排序

**优先级**：

| 层级 | 来源类型 | 具体平台 |
|-----|---------|---------|
| 🥇 官方/监管 | 法规公告 | 证监会、沪深交易所、基金公司官网、巨潮资讯(cninfo.com.cn) |
| 🥈 头部财经媒体 | 专业报道 | 财联社、证券时报、中国证券报、上海证券报、第一财经(yicai.com) |
| 🥉 综合财经平台 | 聚合数据 | 东方财富、同花顺、新浪财经、网易财经、凤凰财经 |
| 4️⃣ 研究机构 | 深度研报 | 中信研报、中金研报、华泰研报、国泰君安研报、万得(Wind)、彭博中文 |
| 5️⃣ 商业/科技媒体 | 行业洞察 | 36氪、虎嗅、钛媒体（科技/消费行业基金适用） |
| 6️⃣ 社区舆情 | 投资者情绪 | 雪球(xueqiu.com)、东方财富股吧/基金吧、微博财经 |
| 7️⃣ 海外媒体 | 跨市场视角 | 路透中文、彭博中文、CNBC中文、南华早报中文 |

### 3. 去重策略

**避免重复搜索**：
- 检查本地 `raw_data/` 目录，已抓取的数据不再重复搜索
- 相同新闻来源只抓取一次
- 相似标题的新闻合并处理

## 📊 搜索结果评估

### 关联性评分（0-100分）

**评分维度**：

| 维度 | 分值 | 说明 |
|-----|------|------|
| 直接提及基金代码 | +40分 | 明确提到基金代码或全称 |
| 涉及重仓股 | +30分 | 根据持仓占比加权（占比×30） |
| 信息来源权威 | +20分 | 官方/头部媒体得满分 |
| 时效性强 | +10分 | 3天内=10分，7天内=7分，30天内=3分 |

**评级标准**：
- **高关联 (80-100分)**：必须保存，生成单条 summary
- **中关联 (50-79分)**：建议保存，生成单条 summary
- **低关联 (<50分)**：不保存，仅记录在日志

**示例**：
```
新闻：宁德时代发布Q1财报，净利润增长48.5%

评分计算：
- 未直接提及基金代码：0分
- 涉及重仓股（占比8.5%）：8.5% × 30 = 25.5分
- 来源：财联社（权威）：20分
- 时效：今天发布：10分
总分：55.5分 → 中关联，建议保存
```

## 📁 搜索结果保存

### 即时保存原则

**每轮搜索后立即保存**，不要等到最后统一保存！

**保存内容**：

## ⚠️ 注意事项

1. **先本地后网络**：优先读取本地历史数据，减少重复搜索

## 💬 阶段七：社区舆情与ETF资金流搜索（新增）

**目的**：追踪散户情绪拐点与机构资金动向，作为反向指标或趋势确认信号

### 1. 雪球/股吧舆情搜索

```
site:xueqiu.com "{基金代码}" OR "{基金名称}" 最近
site:guba.eastmoney.com "{基金代码}" 最近讨论
"{基金名称}" AND ("赎回" OR "抄底" OR "割肉") 最近3天
```

**情绪判断**：
- 大量"赎回"、"亏死了"讨论 → 恐慌底部信号（可能反转）
- 大量"抄底"、"加仓"讨论 → 过热警告（谨慎追高）

### 2. 行业ETF资金流搜索

**原理**：ETF净申赎是机构/大资金风向标

```
搜索格式：
"{行业}" ETF AND ("净申购" OR "净赎回" OR "份额变化") 最近一周

示例：
"新能源ETF" AND ("份额" OR "净值") 最近一周
"科创50" OR "创业板ETF" AND "资金流入" 最近
"恒生科技ETF" AND "净申购" 最近
```

**输出**：

## 🔄 阶段六：经济周期定位

**目的**：判断当前所处经济周期阶段，指导行业配置方向

**执行频率**：每月执行一次（而非每次搜索）

### 经济周期判断框架

```
四周期模型：

复苏期（GDP回升 + 通胀低）：
  → 利好：消费、科技、成长股
  → 不利：防御性板块（公用事业）

过热期（GDP高 + 通胀升）：
  → 利好：资源（能源、有色、原材料）
  → 不利：利率敏感成长股

滞胀期（GDP下行 + 通胀高）：
  → 利好：能源、农业、防御性股票
  → 不利：几乎所有非必需消费

衰退期（GDP下行 + 通胀低）：
  → 利好：债券、医疗、公用事业
  → 不利：周期性行业
```

### 判断所需搜索

```
搜索内容：
1. 最新GDP增速（季度数据）
2. CPI / PPI 最新数据
3. PMI（制造业/服务业）
4. 央行货币政策立场（宽松/中性/收紧）
5. 工业企业利润数据

综合判断：
→ 以 GDP趋势 + CPI走向 确定象限
→ 输出：当前周期阶段 + 对各持仓基金的影响
```

### 周期判断输出格式

```markdown
## 🔄 经济周期定位（2026-05）

**核心指标**：
- GDP 增速：5.2%（同比，Q1 2026）→ 稳定
- CPI：2.1%（同比，2026-04）→ 温和上行
- PMI：50.8（2026-04）→ 扩张区间
- 货币政策：中性偏松

**周期判断**：✅ 复苏期（偏向过热转换区间）

**对持仓的影响**：
- 003984（新能源）：✅ 利好（成长股在复苏期受益于流动性）
- 如持有消费基金：✅ 利好（消费复苏）
- 如持有债券基金：⚠️ 中性偏空（利率可能上行）

**配置建议**：当前周期支持维持成长型基金配置
```
